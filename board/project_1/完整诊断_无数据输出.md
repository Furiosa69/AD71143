## 🎯 核心问题

**AD71143已配置，但不输出数据。** 可能原因：

### 1. ad71143_ctrl状态机未运行 ⚠️⚠️⚠️

检查`ad71143_ctrl`的输入：
```verilog
// top.v:689-709
ad71143_ctrl u_ad71143_ctrl (
    .clk         (clk_100m),
    .rst_n       (rst_n_100m),
    .frame_start (frame_start_100m),  ← 这个信号是否有脉冲？
    ...
);
```

**如果`frame_start_100m`没有脉冲**：
- `ad71143_ctrl`永远停在`S_IDLE`
- 不会输出SYNC/ACLK
- AD71143不会响应

### 2. CDC时序问题

`frame_start`从50MHz跨到100MHz：
```
50MHz gate_clk:  frame_start (top FSM)
    ↓ toggle CDC
100MHz clk_100m: frame_start_100m (ad71143_ctrl)
```

**可能问题**: CDC丢失脉冲或延迟过大

### 3. 时序参数不匹配AD71143规范

当前配置：
```verilog
.ACLK_PULSES  (9),     // 9个ACLK脉冲
.LINE_CYCLES  (6000),  // 60μs @ 100MHz
```

但AD71143 Pipeline模式需要特定的时序。
