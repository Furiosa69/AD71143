# AD71143 条纹数据诊断报告

## 问题现象
上位机接收到的数据：
```
Panel 1 通道值（8 个通道 × 16 bits）：
  通道 0:     0 (0x0000)  ← 饱和下限
  通道 1: 65535 (0xFFFF)  ← 饱和上限
  通道 2:     0 (0x0000)  ← 饱和下限
  通道 3: 65535 (0xFFFF)  ← 饱和上限
  通道 4:     0 (0x0000)
  通道 5: 65535 (0xFFFF)
  通道 6:     0 (0x0000)
  通道 7: 65535 (0xFFFF)
```

**特征**: 奇偶通道交替出现ADC满量程输出（0x0000/0xFFFF），典型的**ADC输入饱和**问题。

## 根本原因分析

### 1. **REFDAC配置过低** ⚠️ 主要问题

**当前配置** (`top.v:507`):
```verilog
(cfg_reg_idx == 4'd0) ? 10'h020 :  // Reg3: AZEN=0, REFDAC=32, ~1.0V
```

**寄存器3 (REFDAC) 位域解析**:
```
Reg3[9:6] = AZEN     = 0 (禁用自动清零)
Reg3[5:0] = REFDAC   = 0x20 = 32
```

**问题**:
- REFDAC=32 对应参考电压约 **1.0V**
- AD71143的输入范围受REFDAC控制
- **REFDAC过低会导致**：
  - 像素信号超出ADC输入范围
  - 亮像素→饱和到0xFFFF
  - 暗像素→饱和到0x0000
  - 表现为黑白条纹（无灰度）

### 2. **IFS增益配置不当** ⚠️ 次要问题

**当前配置** (`top.v:508`):
```verilog
(cfg_reg_idx == 4'd1) ? 10'h005 :  // Reg0: PWR=Normal(000), IFS=15 (中低增益)
```

**寄存器0 (PWR & IFS) 位域解析**:
```
Reg0[9:7] = PWR = 000 (Normal模式)
Reg0[6:3] = 保留
Reg0[2:0] = IFS = 101 = 5 (对应增益倍数)
```

**问题**:
- IFS=5 增益较低
- 如果探测器输出信号本身较弱，低增益会导致：
  - 信号幅度不足
  - 动态范围利用率低
  - 容易受噪声影响

### 3. **CDS时序可能不匹配** ⚠️ 潜在问题

**当前配置**:
```verilog
(cfg_reg_idx == 4'd4) ? 10'h082 :  // Reg4: INTRST_C=8, INTRST_O=2
(cfg_reg_idx == 4'd5) ? 10'h013 :  // Reg5: CDS1_C=1, CDS1_O=3
(cfg_reg_idx == 4'd6) ? 10'h046 :  // Reg6: CDS2_C=4, CDS2_O=6
(cfg_reg_idx == 4'd7) ? 10'h025 :  // Reg7: FA_CDS1=2, FA_CDS2=5
```

**问题**:
- CDS（相关双采样）时序必须匹配探测器的Reset/Signal时序
- 如果时序不匹配：
  - CDS1采样到Reset电平
  - CDS2采样到Signal电平
  - 差分结果可能饱和

## 修复方案

### 方案1: 调整REFDAC（推荐优先尝试）

根据AD71143 SPEC Table 12，REFDAC范围 0~63，对应参考电压：
- REFDAC=32 → ~1.0V（当前值）
- REFDAC=40 → ~1.25V
- REFDAC=48 → ~1.5V
- REFDAC=56 → ~1.75V

**建议值**: REFDAC=48 (1.5V)

```verilog
// 修改 top.v:507
(cfg_reg_idx == 4'd0) ? 10'h030 :  // Reg3: AZEN=0, REFDAC=48, ~1.5V
```

**计算**: 
- Reg3[9:6] = 0 (AZEN=0)
- Reg3[5:0] = 48 = 0x30
- 完整寄存器值 = 0x030

### 方案2: 调整IFS增益（如方案1不够）

根据AD71143 SPEC Table 4，IFS可调范围：
- IFS=0~7 对应不同增益倍数
- 当前 IFS=5 (中低增益)

**建议值**: IFS=3 (中等增益)

```verilog
// 修改 top.v:508
(cfg_reg_idx == 4'd1) ? 10'h003 :  // Reg0: PWR=Normal(000), IFS=3 (中等增益)
```

### 方案3: 启用自动清零AZEN（高级优化）

如果探测器暗电流较大，可启用AZEN：

```verilog
// 修改 top.v:507
(cfg_reg_idx == 4'd0) ? 10'h1B0 :  // Reg3: AZEN=1, REFDAC=48
```

**计算**:
- Reg3[9:6] = 0110 = 6 (AZEN=1, 自动清零使能)
- Reg3[5:0] = 48 = 0x30
- 完整寄存器值 = 0x1B0

## 修复步骤（按优先级）

### 第1步: 提高REFDAC ⭐⭐⭐
```verilog
// top.v:507 修改
10'h020 → 10'h030  // REFDAC: 32→48 (1.0V→1.5V)
```

**预期效果**: 
- ADC输入范围扩大
- 减少饱和现象
- 出现灰度过渡

### 第2步: 如仍饱和，继续提高REFDAC
```verilog
10'h030 → 10'h038  // REFDAC: 48→56 (1.5V→1.75V)
```

### 第3步: 如信号太弱，降低IFS增益
```verilog
// top.v:508 修改
10'h005 → 10'h003  // IFS: 5→3 (降低增益)
```

### 第4步: 检查探测器偏置电压
- 确认探测器的VDD/VSS电压是否正常
- 检查ROIC的偏置电路是否工作

## 验证方法

### 1. 检查数据分布
修改后，正常数据应该：
```
通道值范围: 1000 ~ 60000 (有灰度层次)
均值约: 32768 (中间值)
标准差: 取决于图像内容
```

### 2. 观察直方图
- 原问题: 只有0和65535两个峰值
- 修复后: 应该有连续的灰度分布

### 3. 计算有效位数
```python
dynamic_range = max_value - min_value
effective_bits = log2(dynamic_range)
# 目标: effective_bits > 12 (至少利用12位ADC)
```
