## 如果仍无数据，检查以下信号

### 必须确认的信号（添加到ILA）：

```verilog
// 在top.v的ILA中添加
probe_spi_cfg:   cfg_all_done      // SPI配置完成标志
probe_sync:      sync_p1           // SYNC信号输出
probe_aclk:      aclk_p1           // ACLK信号输出
probe_init:      ctrl_init_done    // AFE初始化完成
```

### 预期值：
```
cfg_all_done = 1    ← 必须为1
sync_p1      = 脉冲  ← 每行开始有低电平脉冲
aclk_p1      = 脉冲  ← 每行有9个50MHz脉冲
ctrl_init_done = 1  ← 必须为1
```
