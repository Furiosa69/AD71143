# 图像黑白条纹问题诊断报告

## 问题描述
运行工程后，显示图像为**黑白条纹夹杂少量噪点**

## 根本原因分析

### 1. **CPV周期配置过大** ⚠️ 主要问题
**位置**: `top.v:791`  
**原配置**: `CPV_PERIOD_US = 10` (10μs)  
**问题**:
- NT39565D手册第6页注释明确指出："Gout为2个CPV周期"
- 手册预测 Gout min = 10.64μs，即 CPV min ≈ 5.32μs
- 手册实测注释："实际调试发现本产品可以支持到2.0μs的CPV"
- **当前10μs的CPV导致每行Gate输出时间过长**，扫描速度慢

**计算**:
- 当前: 每行时间 = 2×10μs = 20μs
- 541行总时间 = 541×20μs = 10.82ms
- **问题**: Gate扫描太慢，与AD71143数据采集不同步

### 2. **OE输出使能占空比过小** ⚠️ 次要问题
**位置**: `top.v:795`  
**原配置**: `OE_PW_US_X10 = 10` (1μs)  
**问题**:
- OE信号控制Gate输出的有效时间窗口
- 1μs @ CPV=10μs = 仅10%占空比
- **导致Gate输出脉冲过窄，像素充电时间不足**
- 表现为细条纹或低亮度

### 3. **帧间隔过短** ⚠️ 次要问题
**位置**: `top.v:9`  
**原配置**: `FRAME_GAP_CYCLES = 100` @ 50MHz = 2μs  
**问题**:
- 帧间隔仅2μs，不足以让显示系统稳定
- 可能导致帧叠加或闪烁

## 修复方案

### 已修复的参数

#### 1. CPV周期优化
```verilog
// 修改前
.CPV_PERIOD_US     (10  ),  // 10μs

// 修改后
.CPV_PERIOD_US     (6   ),  // 6μs (Gout=12μs，符合手册推荐)
```
**依据**: NT39565D手册注释实测可到2μs，使用6μs作为保守值

#### 2. CPV占空比调整
```verilog
// 修改前
.CPV_PW_US_X10     (10  ),  // 1μs (10% duty)

// 修改后
.CPV_PW_US_X10     (30  ),  // 3μs (50% duty)
```
**依据**: 标准时钟信号应为50%占空比

#### 3. OE输出窗口扩大
```verilog
// 修改前
.OE_PW_US_X10      (10  ),  // 1μs (10% duty)

// 修改后
.OE_PW_US_X10      (45  ),  // 4.5μs (75% duty)
```
**依据**: 
- NT39565D手册第5页："OE goes high, output will pulled to low level (VEE)"
- 需要足够的OE低电平时间让Gate输出VGG，为像素充电
- 75%占空比提供充足的像素充电时间

#### 4. 帧间隔延长
```verilog
// 修改前
parameter integer FRAME_GAP_CYCLES = 100,  // 2μs @ 50MHz

// 修改后
parameter integer FRAME_GAP_CYCLES = 250000,  // 5ms @ 50MHz
```
**依据**: 给予显示系统足够的帧间稳定时间

## 修复后的时序计算

### Gate Driver时序
- CPV周期: 6μs
- 每行Gout时间: 2×6μs = 12μs
- 541行扫描时间: 541×12μs = 6.492ms
- 帧率: 1/(6.492ms + 5ms) ≈ 87 fps

### OE窗口时序
- OE低电平时间: 4.5μs (Gate输出VGG)
- OE高电平时间: 1.5μs (Gate输出VEE)
- 占空比: 75% (充足的像素充电时间)
