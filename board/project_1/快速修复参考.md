# 黑白条纹问题修复汇总

## 问题定位

✅ **真正原因**: AD71143 ADC输入饱和（不是NT39565D的Gate驱动问题）

**证据**: 上位机数据显示奇偶通道交替出现 0x0000/0xFFFF，典型的ADC饱和特征

## 核心修复（2处）

### 1. REFDAC参考电压 ⭐⭐⭐ 最关键
```verilog
// top.v:507
10'h020 → 10'h030  // REFDAC: 32→48 (1.0V→1.5V)
```
**作用**: 扩大ADC输入范围，避免信号饱和

### 2. IFS增益调整 ⭐⭐
```verilog
// top.v:508
10'h005 → 10'h003  // IFS: 5→3 (降低增益)
```
**作用**: 降低前端增益，配合REFDAC防止饱和

## 附加优化（Gate驱动时序）

虽然不是主要问题，但也一并优化了NT39565D时序：

### 3. CPV周期优化
```verilog
// top.v:791
CPV_PERIOD_US: 10 → 6  // 加快扫描速度
```

### 4. OE占空比扩大
```verilog
// top.v:795
OE_PW_US_X10: 10 → 45  // 扩大Gate输出窗口
```

### 5. 帧间隔延长
```verilog
// top.v:9
FRAME_GAP_CYCLES: 100 → 250000  // 增加帧间稳定时间
```

## 如果仍有问题

### 如果数据仍然饱和到0xFFFF
```verilog
// 继续提高REFDAC
10'h030 → 10'h038  // REFDAC: 48→56 (1.5V→1.75V)
```

### 如果数据太弱（都接近0x0000）
```verilog
// 提高IFS增益
10'h003 → 10'h004  // IFS: 3→4 (提高增益)
```

### 如果数据正常但图像偏暗/偏亮
→ 这是正常现象，在上位机软件中调整**显示窗宽窗位**即可
